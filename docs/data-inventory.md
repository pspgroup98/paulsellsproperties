Data categories collected or processed by paulsellsproperties.com.

## Automatically Collected Data (Analytics)

| Data Category | Service | Purpose | PII? | Retention |
|--------------|---------|---------|------|-----------|
| Page URLs visited | GA4, Clarity | Usage analytics | No | GA4: 14 months; Clarity: per Microsoft policy |
| Session duration | GA4 | Usage analytics | No | 14 months |
| General location (country, city) | GA4 | Usage analytics | No (not precise) | 14 months |
| Browser type and version | GA4, Clarity | Technical compatibility | No | Per service policy |
| Device type (mobile/desktop/tablet) | GA4, Clarity | Usage analytics | No | Per service policy |
| Referring site (where visitor came from) | GA4 | Traffic source analysis | No | 14 months |
| Scroll depth milestones | GA4 | Content engagement | No | 14 months |
| Click events (CTAs, external links) | GA4 | Engagement analytics | No | 14 months |
| Session recordings (mouse, scroll, clicks) | Clarity | UX/design improvement | No (input masked) | Per Microsoft policy |
| Heatmaps | Clarity | UX/design improvement | No | Per Microsoft policy |
| IP address | GA4, Clarity, GitHub Pages | Network-level processing only; not stored by us | Yes (processed) | Not stored by us |
| Font requests (IP) | Google Fonts | Font delivery | Yes (server log) | Per Google policy |

**Note:** Form input fields are masked in Clarity by default — keystrokes are not recorded.

| Key | Storage Type | Value | Purpose | Shared? |
|-----|-------------|-------|---------|---------|
| `psp_analytics` | localStorage | `"granted"` or `"denied"` | Analytics consent preference | No — per-browser only |

No cookies are set by this site's own code. Third-party cookies may be set by GA4 and Clarity per their own policies.

## Data NOT Collected

The following data categories are explicitly not collected or processed by this site:

- Exact geolocation coordinates
- Social media profile data
- Financial account information
- Income or credit information
- Government-issued ID numbers
- Health information
- Authentication credentials
- Cross-site behavioral profiles (no advertising pixels)
- Biometric data
